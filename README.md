
# Tape Sorter

Консольное приложение на C++, предназначенное для сортировки целых чисел по возрастанию в модели устройства хранения данных типа *лента*.

Программа учитывает ограничение на объём используемой оперативной памяти, работает с конфигурационным файлом и поддерживает как бинарные, так и обычные текстовые входные и выходные файлы.



## Возможности

Программа позволяет:

- сортировать целые числа по возрастанию;
- задавать входной и выходной файл через аргументы командной строки;
- использовать внешний конфигурационный файл `config.txt`;
- настраивать задержки чтения, записи, перемещения и перемотки ленты;
- задавать ограничение на объём данных, одновременно обрабатываемых в оперативной памяти;
- работать с файлами формата `.txt` и `.bin`;
- запускать модульные тесты на Boost.Test.


## Требования

### Общие требования

Для сборки основной программы необходимы:


- компилятор C++ с поддержкой **C++20**;
- **CMake** версии 3.16 или выше.

Для сборки и запуска тестов дополнительно требуются Boost headers.

## Сборка проекта

### Ubuntu / WSL / Linux

#### Сборка проекта вместе с тестами

Из корня проекта выполнить:

```bash
cmake -S . -B build
cmake --build build
```
После сборки будут созданы:

```text
build/tape_sorter
build/tape_sorter_tests
```

#### Сборка только основной программы без тестов

Если требуется собрать только приложение без тестового исполняемого файла, можно отключить сборку тестов:

```bash
cmake -S . -B build -DBUILD_TESTING=OFF
cmake --build build
```

После такой сборки будет создан только основной исполняемый файл:

```text
build/tape_sorter
```

---

### Windows через терминал CMake

При наличии установленного CMake и подходящего компилятора проект также можно собрать из терминала.

#### Сборка проекта вместе с тестами

## Конфигурационный файл

Настройки задаются в файле:

```text
config.txt
```

Пример содержимого:

```text
read_delay_ms=0
write_delay_ms=0
move_delay_ms=0
rewind_delay_ms=0
m_limit_bytes=12
```

### Параметры

| Параметр | Назначение |
|---|---|
| `read_delay_ms` | задержка чтения одного элемента в миллисекундах |
| `write_delay_ms` | задержка записи одного элемента в миллисекундах |
| `move_delay_ms` | задержка перемещения ленты на одну позицию в миллисекундах |
| `rewind_delay_ms` | задержка перемотки ленты в миллисекундах |
| `m_limit_bytes` | максимальный объём данных, одновременно обрабатываемых в оперативной памяти |

После изменения `config.txt` пересобирать проект не требуется. Достаточно запустить программу заново.

## Форматы файлов

Программа поддерживает два типа входных и выходных файлов.

### Текстовый формат `.txt`

Текстовый файл содержит целые числа, разделённые пробелами или переводами строк.

Пример:

```text
100 -5 0 42 42 -100 7 3 1
```

При работе с `.txt`-файлами программа самостоятельно выполняет необходимое внутреннее преобразование.

---

### Бинарный формат `.bin`

Бинарный файл содержит последовательность 32-битных целых чисел.

Этот формат используется для непосредственной работы с эмуляцией ленты.

## Запуск программы

Общий формат запуска:

```bash
./build/tape_sorter <input_file> <output_file>
```

---

## Возможные варианты запуска

### 1. Текстовый вход → текстовый выход

```bash
./build/tape_sorter input.txt output.txt
```

Если `input.txt` содержит:

```text
100 -5 0 42 42 -100 7 3 1
```

то в `output.txt` будет записано:

```text
-100 -5 0 1 3 7 42 42 100
```

---

### 2. Текстовый вход → бинарный выход

```bash
./build/tape_sorter input.txt output.bin
```

На выходе будет создан бинарный файл с отсортированными значениями.

---

### 3. Бинарный вход → текстовый выход

```bash
./build/tape_sorter input.bin output.txt
```

На выходе будет создан текстовый файл с отсортированными числами.

---

### 4. Бинарный вход → бинарный выход

```bash
./build/tape_sorter input.bin output.bin
```

На выходе будет создан бинарный файл с отсортированными значениями.

---

## Пример полного запуска

Создать входной текстовый файл:

```bash
echo "100 -5 0 42 42 -100 7 3 1" > input.txt
```

Запустить сортировку:

```bash
./build/tape_sorter input.txt output.txt
```

Посмотреть результат:

```bash
cat output.txt
```

Ожидаемый результат:

```text
-100 -5 0 1 3 7 42 42 100
```

## Временные файлы

Во время работы программа использует временные файлы в директории:

```text
tmp/sort_work
```

Они создаются автоматически и используются для промежуточных операций сортировки.
После успешного завершения сортировки рабочие временные файлы удаляются автоматически.

## Тесты

В проекте используются модульные тесты на Boost.Test.

Тесты собираются, если параметр `BUILD_TESTING` включён. По умолчанию он имеет значение `ON`.

### Сборка и запуск тестов

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
Тесты также можно запустить напрямую:

./build/tape_sorter_tests

---

## Возможные ошибки при запуске

### Программа запущена без аргументов

Пример некорректного запуска:

```bash
./build/tape_sorter
```

В этом случае будет выведена подсказка по корректному формату команды.

---

### Ошибка в `config.txt`

Программа завершится с ошибкой, если:

- отсутствует обязательный параметр;
- один параметр указан несколько раз;
- указан неизвестный параметр;
- значение параметра не является числом.

---

### Ошибка в текстовом входном файле

Если `.txt`-файл содержит нецелочисленные данные, программа завершится с ошибкой.

Например, некорректный файл:

```text
10 20 abc 30
```

---

### Слишком маленькое значение `m_limit_bytes`

Если ограничение памяти меньше размера одного элемента `int32_t`, сортировка невозможна, и программа завершится с ошибкой.
